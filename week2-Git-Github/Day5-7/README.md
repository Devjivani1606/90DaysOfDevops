🧠 Key Concepts I Understood

One of the most important lessons from this week was understanding that Linux is not just a collection of commands.

I learned:

Applications
     ↓
Shell
     ↓
Kernel
     ↓
Hardware

Every command eventually reaches the kernel, and the kernel communicates with the hardware.

Another important concept was understanding the Linux startup process:

Power Button
      ↓
BIOS / UEFI
      ↓
GRUB Bootloader
      ↓
Linux Kernel
      ↓
systemd
      ↓
Services
      ↓
User Login

This helped me understand what happens behind the scenes when a Linux machine starts.
